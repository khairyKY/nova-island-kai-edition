# Nova Island media companion

Identifies YouTube, YouTube Music, Spotify Web, Apple Music, SoundCloud, Vimeo and Twitch media without changing tabs or using browser UI Automation. Native players use Windows media sessions and do not need this extension.

Load this folder using **Extensions → Developer mode → Load unpacked** in Opera GX, Chrome or Edge. The native messaging host is registered by Nova Island. Keep this folder in place. The extension badge displays `…` while Nova is disconnected.

The extension reads tab titles and media metadata for the listed sites only and sends a bounded, temporary report to Nova on this computer. It does not send browsing data to a server or inspect private windows. If multiple sources match, Nova keeps the browser icon instead of guessing.
